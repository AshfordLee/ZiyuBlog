# 文档说明

本文档记载一次MLE的预训练和极小的微调

## 实验数据

从生成的长对话里面提取出来的树，总共100颗，88样本内，12val，树比较大，大概每棵树有150个fact+50个aspect，大概共200个节点

## 实验过程

首先是用chatgpt-4o做标注，也就是对每个snapshot的closure，让gpt去决定应该做什么动作，这就得到了所有的(X,y)，做监督学习

这些(X,y)做100个epoch的监督学习

结束之后，做online学习，但只做两个policy，online的成本非常高，2个epoch大概跑了10小时

## 评判结果

从结构上来说，teacher(gpt)和student(小模型)做出来的树的aspect都比较少，至少比数据集里面的原树少得多

<img src="/images/memory_part4/image1.png" alt="label_plot" />

用gpt5.6-sol当强模型，直接分别给ref, teacher, student树打分如下(理论上student的分不可能超过teacher)

<img src="/images/memory_part4/image2.png" alt="label_plot" />

从这个图上可以看出来，teacher的质量其实也一般，或者说teacher在看不到ref_tree的情况下，应该不太可能做到比较好
